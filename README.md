# Study Tour Proposal Document Generator

An automated, print-ready web application for generating study tour proposal documents (Proformas, Student Rosters with Escorting Staff, Field Itineraries, and Syllabus-Linked Financial Budget Proposals) for higher education institutions.

Pre-loaded with the **Government Victoria College, Palakkad (PG & Research Department of Botany)** study tour proposal documents (Plan Fund 2025–26).

---

## 🚀 Live Demo on GitHub Pages
Visit the live application: **[https://sureshmagnolia.github.io/StudyTourProposal/](https://sureshmagnolia.github.io/StudyTourProposal/)**

---

## ✨ Features

- **Standard University Proforma**: Official 15-point proforma generation per class with live Boy/Girl/Total count updates, syllabus justification, and dual signature sections (HOD & Principal).
- **Class Rosters & Faculty Escort Allocation**: Enrolled student lists with Sl. No., Name, Gender, Age, and Accompanying/Lady Escort faculty assignments.
- **Detailed Field Itinerary Planner**: Multi-day schedule builder (Time, Starting Point, Destination, Academic/Botanical activities).
- **Syllabus-Linked Financial Budget Engine**: Dynamic calculation of total student days and total cost based on syllabus practical requirements, auto-generating grand totals and Indian currency amount in words (*e.g., RUPEES TWO LAKH TWENTY THOUSAND ONLY*).
- **Bulk Import from Excel**: Quickly paste tabular data copied directly from Excel / Google Sheets to populate student lists.
- **Print-Ready A4 Layout**: Optimized with clean `@media print` CSS for standard A4 page printing or direct PDF export.
- **Data Portability**: Auto-save to LocalStorage, JSON configuration export and import, and one-click reset to default preset.
